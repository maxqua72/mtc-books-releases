# MTC Book

Programma per scrivere libri di scacchi. Questa pagina contiene l'app per Windows.

**[Scarica l'ultima versione](https://github.com/maxqua72/mtc-books-releases/releases/latest)** (file `MTC-Book-Setup-x.y.z.exe`, Windows 64 bit).

## Installazione

1. Scarica e avvia il file. Windows mostra «Windows ha protetto il PC» perché il programma non è ancora firmato digitalmente: clicca **Maggiori informazioni** e poi **Esegui comunque**.
2. Segui la procedura guidata. L'app si installa solo per il tuo utente.
3. Il doppio clic su un file `.mtcbook` lo apre in MTC Book.

## Cose da sapere

- **I tuoi libri.** MTC Book conserva una copia di lavoro nell'app, ma il salvataggio che conta è il file `.mtcbook`: usa «Salva Lavoro». Se il libro ha un file, si salva anche da solo dopo 30 secondi senza modifiche, e prima del salvataggio viene creata una copia `.bak` della versione precedente.
- **Esportazione in PDF.** Si fa nell'app, direttamente sul tuo computer, senza inviare nulla in rete.
- **Motore di scacchi (facoltativo).** MTC Book non include nessun motore. Per l'analisi scarica un motore UCI (ad esempio Stockfish dal sito ufficiale) e indicane il programma nella scheda *Motore*.
- **Aggiornamenti.** L'app li cerca da sola. Puoi controllarli dal menu *Aiuto*.
- **Disinstallazione.** Da *App installate* di Windows. I dati dell'app restano in `%APPDATA%\MTC Book`: cancellali a mano se non ti servono più.
- **Antivirus.** Un programma non firmato può essere segnalato per errore: se succede, scrivici.
